# Документация API

## 1. GET /api/text
* **Описание:** Возвращает простой приветственный текст.
* **Запрос:** `GET http://localhost:1880/api/text`
* **Ответ (200 OK):**
```text
Привет от студента Лисай!
```

---

## 2. GET /api/info
* **Описание:** Возвращает JSON-объект с информацией о студенте.
* **Запрос:** `GET http://localhost:1880/api/info`
* **Ответ (200 OK):**
```json
{
  "student": "Лисай",
  "group": "УИР",
  "status": "Active"
}
```

---

## 3. GET /api/items
* **Описание:** Возвращает данные объекта по его идентификатору `id`.
* **Параметры запроса:** `id` (Query-параметр)

### 3.1. Успешный запрос
* **Запрос:** `GET http://localhost:1880/api/items?id=1`
* **Ответ (200 OK):**
```json
{
  "id": 1,
  "name": "Предмет 1",
  "owner": "Лисай"
}
```

### 3.2. Ошибка: не передан обязательный параметр id
* **Запрос:** `GET http://localhost:1880/api/items`
* **Ответ (400 Bad Request):**
```json
{
  "error": "Параметр 'id' обязателен (например, ?id=1)"
}
```

### 3.3. Ошибка: элемент с запрашиваемым ID не найден
* **Запрос:** `GET http://localhost:1880/api/items?id=999`
* **Ответ (404 Not Found):**
```json
{
  "error": "Предмет с таким ID не найден"
}
```
