# Работа с Redis в n8n

## Описание
В данной части лабораторной работы была настроена интеграция n8n с базой данных Redis, работающей в Docker-контейнере.

## Настройка подключения
- **Host**: `host.docker.internal` (для доступа из контейнера n8n к хост-машине)
- **Port**: `6379`
- **Password**: не требуется

## Выполненные действия
1. **Создание и чтение (flow-09)**: 
   - С помощью операции `Set` в Redis была записана пара ключ-значение (ключ: `lisay`, значение: `Test value from n8n lab4`).
   - С помощью операции `Get` значение было успешно прочитано и возвращено в workflow.
2. **Удаление и проверка (flow-10)**:
   - С помощью операции `Delete` ключ `lisay` был удалён из базы данных.
   - С помощью операции `Exists` была подтверждена успешная операция удаления (результат: `false` / `0`, что означает отсутствие ключа).

## Вывод
Redis успешно интегрирован в n8n через стандартные ноды. Операции Set, Get, Delete и Exists работают корректно и могут быть использованы для хранения временных данных или состояния между запусками workflow.
